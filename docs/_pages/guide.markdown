# 支持的功能

### 音游功能

#### 舞萌DX

| 功能名称                                                   | 使用方法                                                       | 群聊可用 | 频道可用 |
|--------------------------------------------------------|------------------------------------------------------------|------|------|
| Best 50                                                | **b50**                                                    | 是    | 是    |
| 设置b50 ([头像列表](/maimai_icons)) ([牌子列表](/maimai_plates)) | **设置b50** *设置项* *值*                                        | 是    | 是    |
| 今日舞萌                                                   | **今日舞萌**                                                   | 是    | 是    |
| 随机歌曲                                                   | **随个&lt;难度&gt;等级** <br>例：随个紫13+<br>例：mai什么推分               | 是    | 是    |
| 查歌                                                     | **查歌** *歌名*                                                | 是    | 是    |
| 定数查歌                                                   | **定数查歌** *定数*                                              | 是    | 是    |    
| 谱师查歌                                                   | **谱师查歌** *谱师名称* *页数*                                       | 是    | 是    |    
| 正则查歌                                                   | **正则查歌** *正则表达式*                                           | 是    | 是    |    
| 根据别名查歌                                                 | **歌名是什么歌**                                                 | 是    | 是    |
| 谱面信息                                                   | **（难度）id** *编号*<br>  例：id 799<br> 例：紫id432                 | 是    | 是    |
| 查询现有别名                                                 | **编号有什么别名**<br> 例：432有什么别名                                 | 是    | 是    |
| 分数线                                                    | **分数线** *帮助*                                               | 是    | 是    |
| 猜歌                                                     | **猜歌**                                                     | 是    | 是    |
| 舞萌开字母小游戏                                               | **舞萌开字母**                                                  | 是    | 否    |
| 设置猜歌                                                   | **设置猜歌 启用/关闭**                                             | 是    | 是    |
| AP50                                                   | **ap50**                                                   | 是    | 是    |
| info                                                   | **info** *&lt;歌曲id/名称/别名&gt;* <br>例：info 潘<br>例：info 11451 | 是    | 是    |
| 完成表                                                    | **&lt;等级/牌子&gt;完成表**<br>例：堇将完成表<br>14完成表                   | 是    | 是    |
| 分数列表                                                   | **&lt;等级&gt;分数列表 &lt;页数&gt;**<br>例：13+分数列表<br>例：13分数列表 2   | 是    | 是    |

#### 机厅排卡

| 功能名称      | 使用方法                                          | 群聊可用 | 频道可用 |
|-----------|-----------------------------------------------|------|------|
| 查看总排卡人数   | **/j**                                        | 是    | 是    |
| 设置群聊/频道机厅 | **排卡管理**                                      | 是    | 是    |
| 设置排卡人数    | **&lt;机厅名&gt;[人数]人** <br>例：csyx5 <br>例：fyzq7人 | 是    | 是    |
| 查看机厅人数    | **&lt;机厅名&gt;几** <br>例：dfc几                   | 是    | 是    |
